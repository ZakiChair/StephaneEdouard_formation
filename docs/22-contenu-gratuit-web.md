# Le contenu gratuit de mat-consulting.fr — ce que le corpus local ne contient pas

> **Pourquoi ce document.** Les 147 fiches de formation sans contenu ne peuvent pas être
> reconstituées depuis le corpus local : il n'y a que la fiche catalogue. Mais le site
> public donne, en gratuit, **le programme de chaque séminaire** et **la voix de l'auteur**
> sur son propre travail. Ce document recense ce qui est publiquement accessible et le
> rattache aux fiches du corpus.

> **Ce n'est pas le cours.** C'est le **programme** (tracklist, objectifs, postulats) et
> l'**extrait vidéo** de chaque formation. Un semelle tracklist ne permet pas de dire
> *voilà le contenu de la formation* — elle permet de dire *cette formation porte
> sur X, Y, Z, et voici l'extrait gratuit*.

**Source** : `https://mat-consulting.fr/catalogue/` — 77 pages produit récupérées
le 2026-10-22 via Firecrawl. **Vidéos** : 35 extraits.

---

## 1. Ce que le site public donne, et que le corpus n'a pas

| Élément | Mesure | Nature |
|---|---|---|
| Pages produit lues | **168** | une par produit du sitemap (le catalogue visible n'en montrait que 78) |
| Avec tracklist (déroulé séance par séance) | 73 | le programme |
| Avec objectifs / postulats | 44 | ce que l'auteur dit vouloir transmettre |
| Avec extrait vidéo gratuit | 52 | le lien vers la vidéo |
| Avec avis clients | 139 | témoignages de participants (source tierce) |
| Volume de tracklist récupéré | **129,626 mots** | |

### Catalogue public : couverture exhaustive

Le catalogue public se parcourt par **3 catégories × 3 pages** :
`efficacite-personnelle`, `hommes-femmes-mode-demployment`… (`hommes-femmes-mode-demploi`),
`hors-seminaires`. Au-delà de la page 3, le catalogue renvoie une page vide.

**Ce catalogue est exhaustif** : 78 formations publiques, 78 pages produit capturées,
0 manquant. L'inventaire avec les empreintes SHA-256 est dans
`_INDEX-CATALOGUE-PUBLIQUE.json`.

Conséquence : les **369 fiches locales** ne sont pas 369 formations mais
**plusieurs sessions** (matin / après-midi) de ces 78 formations. Une fiche locale
sans équivalent dans le catalogue est donc une session dont la formation
mate est identifiée — c'est ce qui permet les 138 reconstitutions du livrable 21.

**Rattachement au corpus** : chaque page web est reliée à sa fiche locale par
l'URL de catalogue (`C###`). Les formations dont la fiche locale est vide et dont la
page web apporte une tracklist sont les **candidates prioritaires** à la reconstitution.

| Statut | Nombre |
|---|---|
| Fiche locale déjà verbatim (rien à apporter) | 68 |
| Fiche locale sans verbatim, tracklist disponible | **5** |
| Page web sans correspondance locale | 0 |

## 3. Règles d'usage

| Ce qu'on peut dire | Ce qu'on ne peut pas dire |
|---|---|
| *cette formation porte sur X, Y, Z* (tracklist) | *le cours couvre X* |
| *voici l'extrait gratuit de la formation* (lien) | *la formation explique X* (non vérifié) |
| *l'auteur postule que…* (section postulats) | *l'auteur dit que…* si ce n'est pas cité |

**Citer une page web** : avec son slug et son URL, jamais comme si c'était une citation
de l'auteur. Une tracklist est un **programme**, pas une parole.
