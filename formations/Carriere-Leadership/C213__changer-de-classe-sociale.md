### Résumé

Changer de classe sociale est un travail de conversion de capitaux et d'acquisition de codes qui demande du temps, de la stratégie et du discernement. Les mécanismes de reproduction sociale sont puissants mais pas invincibles — celui qui comprend comment fonctionnent les classes peut naviguer consciemment là où les autres naviguent par héritage.

---

### Points clés

- La classe sociale se change par accumulation et conversion de capitaux
- Les codes (vestimentaires, linguistiques, comportementaux) sont le passeport de classe
- La preuve sociale fonctionne aussi pour monter — les bons réseaux ouvrent les portes
- L'intérêt (75/20/5) est le moteur des dynamics de classe
- Le discernement permet de voir les opportunités là où les autres voient des murs

---

### Concepts enseignés

### Les trois capitaux

**Capital économique** : L'argent, les biens, les ressources. Base nécessaire mais pas suffisante.

**Capital social** : Les réseaux, les relations, les connexions. Capital déterminant pour l'accès aux opportunités.

**Capital symbolique** : Le prestige, l'honneur, la reconnaissance. Capital le plus durable mais le plus long à acquérir.

La conversion des capitaux est le mécanisme central du changement de classe.

### L'acquisition des codes de classe

Les classes sociales se distinguent par des codes :
- **Vestimentaires** : marques, styles, qualité des tissus
- **Linguistiques** : vocabulaire, accent, références culturelles
- **Comportementaux** : manières, savoir-vivre, posture

Ces codes sont transmis familialement mais peuvent être appris. L'homme qui veut changer de classe doit investir dans l'acquisition de ces codes.

### La preuve sociale et les réseaux

Les réseaux déterminent l'accès aux opportunités. La preuve sociale fonctionne dans les deux sens :
- Mauvais réseaux = confirmation de votre classe d'origine
- Bons réseaux = introduction dans la classe supérieure

### L'intérêt comme moteur (75/20/5)

75% des comportements des classes supérieures visent l'intérêt économique. Comprendre cette logique permet de prédire et d'influencer les comportements.

---

### Exercices / Pratiques

- **Audit de capitaux** : Évaluez vos trois capitaux actuels (économique, social, symbolique)
- **Cartographie des réseaux** : Identifiez qui dans vos réseaux peut vous introduire dans des cercles supérieurs
- **Travail sur les codes** : Investissez dans votre apparence, votre langage, vos manières
- **Stratégie de conversion** : Définissez comment vous allez convertir vos capitaux (ex: travail → argent → réseau → prestige)
- **Le test de l'intérêt** : Face aux opportunités, analysez les intérêts en jeu
